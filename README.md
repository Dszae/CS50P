## About CS50P

CS50P is Harvard University's introduction to programming using Python. The course teaches fundamental programming concepts through practical exercises, problem sets, and an independent final project.

This repository is a personal collection of CS50P solutions and learning exercises, intended for revision, reference, and tracking progress through the course.

## Run the Python Solutions

Clone this repository:

```bash
git clone https://github.com/Dszae/CS50P.git
```

Enter the repository directory:

```bash
cd CS50P
```

Run a Python file:

```bash
python filename.py
```

Replace `filename.py` with the path to the exercise you want to run. Some exercises may require user input or additional dependencies.
